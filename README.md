# NORTH. — каталог рабочего пространства

Учебный интернет-магазин с 12 товарами. Каталог работает на HTML, CSS и JavaScript. Товары загружаются из `products.json`, фотографии и шрифт хранятся вместе с исходным кодом.

[Открыть демонстрацию](https://guesti18921.github.io/north-catalog/)

## Локальный запуск

Понадобится Python 3. В корневой папке проекта выполните:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Установка пакетов и сборка не требуются.

## Поведение каталога

- Поиск учитывает название и подзаголовок. Его можно сочетать с категорией, диапазоном цены и любым из четырёх вариантов сортировки.
- При сортировке по популярности товары идут в порядке записей в `products.json`.
- Панель фильтров и карточку товара можно закрыть кнопкой, нажатием на фон или клавишей `Escape`. Закрытие панели сохраняет выбранные фильтры.
- Корзина и избранное действуют до перезагрузки страницы. Корзина показывает количество добавленных товаров.

Шрифт Manrope распространяется по лицензии [OFL](./assets/fonts/OFL-Manrope.txt), пиктограммы Bootstrap Icons — по лицензии [MIT](./assets/icons/LICENSE-Bootstrap-Icons.txt).
